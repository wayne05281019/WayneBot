> **目標**：做成你看大盤的技術底座——不追消息、不賭精準頂底，但要能分辨「相對高檔／相對低檔」與「下跌風險升溫」，避免大盤轉弱還傻傻滿倉接刀。

## 一、你要解的題（不是別人那套）

| 不追求 | 要追求 |
|--------|--------|
| 預測「明天一定跌」 | 辨識**下跌風險升溫**（distribution、量價背離、期現轉弱） |
| 猜最低點 | 標出**相對低檔區**（賣壓衰竭 + 量縮 + 廣度不再惡化） |
| 猜最高點 | 標出**相對高檔區**（追高量、上影、廣度收窄、期貨領跌現貨） |
| 新聞、耳語、法人故事 | **指數本身 + 全市場價量結構 + 台指期** |

和「散戶技術」的差異：不是單看 MA 金叉死叉（那是被設計來讓人晚進早出）。WayneBot 的大盤層要回答：

1. **現在是趨勢延伸、還是末端放量？**（量價位置）
2. **現貨與期貨誰領先？**（領先通常有意義）
3. **漲的是少數權值還是廣度擴散？**（指數失真）
4. **海選桶在這種大盤狀態下歷史勝率如何？**（已有 `backtest_bucket_win_rate_by_regime` 雛形）

## 二、現況（v0 已有什麼）

` taiwan_market.py` 目前已做：

- `index_daily`：加權日 K（Yahoo `^TWII`）→ sqlite，16:30 融合時同步
- **Regime**：bull / neutral / bear（收盤 vs MA20/MA60、20 日斜率、廣度、法人合計）
- **海選加權**：`REGIME_BUCKET_MULT` 依大盤調整各桶排序與上限
- **復盤**：`screen_picks` × `index_daily.regime` 隔日勝率
- **晨間附註**：`format_taiwan_market_brief_html` 附在海選後

**缺口**（你要的「深度」）：

- 沒有**相對高／低檔區**的明確定義與歷史標記
- 沒有**量價結構**（量增價滯、價跌量增、突破量等）
- 沒有**台指期**（近月、夜盤、基差、未平倉）
- Regime 只有三態，無法表達「多頭末端」「空頭衰竭」
- 指數資料來源仍依 Yahoo，需與官方／期交所交叉驗證後才當「庫內真理」

## 五、L2 價量特徵（Wayne 式，非教科書）

### 5.1 相對高檔區（不是最高點）

同時滿足 **≥3 項** 才標「高檔風險」：

1. **位置**：收盤在 60 日區間上 85% 分位以上，且距 20 日高 < 1.5%
2. **量**：近 5 日均量 > 120 日均量 × 1.3，但近 3 日漲幅遞減（量增價滯）
3. **廣度**：指數創高但「站上月線家數%」較前波高點下降（指數失真）
4. **K 線**：近 10 日內 ≥2 根長上影或吞噬後無法新高
5. **期貨**：台指近月連 2 日收低於現貨收（基差轉弱）或夜盤領跌

輸出：`risk_zone = elevated | normal | compressed`（高檔 / 中性 / 壓縮待變）

### 5.2 相對低檔區（不是最低點）

同時滿足 **≥3 項** 才標「低檔觀察」：

1. **位置**：收盤在 60 日區間下 20% 分位，或距 60 日低 < 2%
2. **量**：下跌段量增、最後一根量縮且不再破低（賣壓衰竭）
3. **廣度**：跌家數極端後連 2 日改善（即使指數還沒彈）
4. **波動**：20 日 true range 壓到 120 日低位（變盤前常見）
5. **期貨**：夜盤不再創低、近月開始收高於前日

輸出：`support_zone = watch | building | none`

### 5.3 下跌風險升溫（你要的「別傻傻進場」）

獨立於多空 regime，專用 **falling_risk** 0–100：

| 因子 | 權重（初版） | 說明 |
|------|-------------|------|
| 跌破 MA20 且 3 日內無法站回 | +25 | 短線結構轉弱 |
| 量價：跌日量 > 漲日量（10 日） | +20 | 賣方主導 |
| 廣度 < 35% 站上月線 | +15 | 內部空虛 |
| 台指近月 < 現貨收 連 2 日 | +15 | 聰明錢領跌 |
| 5 日內長黑 > 1.5% 且放量 | +15 | 事件型出貨 |
| 美股隔夜 risk_off（已有） | +10 | 外圍濾網，非主訊號 |

`falling_risk ≥ 60` → 海選：當沖/隔日沖桶再降權；佈局桶要求「獲利格 + 站上月線」雙重。

## 六、L3 狀態機 Regime+（超越 bull/bear）

| 狀態 | 白話 | 海選策略傾向 |
|------|------|--------------|
| `trend_up` | 多頭延伸，廣度配合 | 起漲、周帶量正常權重 |
| `trend_up_late` | 多頭但高檔風險升 | 少追、降 cap、多看獲利格 |
| `range` | 箱型 | 中性，偏選股不賭方向 |
| `trend_down` | 空頭延伸 | 縮短線桶、佈局需極嚴 |
| `down_exhaust` | 空頭末端、低檔觀察 | 黃金買點桶可略放，仍不賭刀 |
| `repair` | 跌後站回 MA20 | 觀察 3 日，不急追 |

狀態轉換用 **滯後**（需連續 2–3 日確認），避免一日震盪洗來洗去。

## 七、台指期與現貨（重點研究）

### 要回答的問題

1. **誰領先**：近 20 日統計「期貨先破低 / 現貨先破低」後 5 日報酬
2. **基差**：`(期貨收 - 現貨收) / 現貨收` 極端值後的均值回歸
3. **夜盤**：美股收盤後台指夜盤方向 → 隔日現貨開盤勝率（與 `us_overnight` 交叉，但不取代）
4. **OI + 價**：價跌 OI 增（空單建）vs 價跌 OI 減（多單停損）→ 下跌是否還有續航

### 與個股的關係（未完成對齊第 17 項）

- 大盤 regime × 個股 β（對指數 60 日相關）→ 高 β 股在 `trend_down` 自動降權
- 電子權值 vs 傳產：用現有 `daily_sector_flow` 分拆，不另做消息

## 八、L4 輸出（完成時你會看到什麼）

1. **早上海選前**：一句大盤人話 + `falling_risk` 燈號（綠/黃/紅）
2. **海選內文**：維持 `format_taiwan_market_brief_html`，加上「相對高/低」與「期現」一行
3. **主選單（規劃）**：「大盤」按鈕 → 專頁圖文（指數 + 風險 + 廣度，不洗版）
4. **個股查詢**：若 `falling_risk` 紅燈，決策卡頂部淡提示「大盤結構偏弱，少追」
5. **AI 模擬倉**：`falling_risk` 高時自動縮倉（與 regime 相乘）

**不會做**：即時推播「快逃」；只給結構與權重，下單仍是你決定。

## 九、驗證方法（避免自嗨）

1. **樣本切割**：2018–2023 訓練規則閾值，2024–至今樣本外
2. **指標**：不是「預測漲跌準確率」，而是  
   - 高檔區後 10 日最大回撤分布  
   - 低檔區後 10 日反彈中位數  
   - 海選桶在 `falling_risk` 高/低時的隔日勝率差
3. **與 CaryBot / 奇摩走勢**：指數收盤價以官方融合日 K 為準，不拿 Yahoo 當唯一真理
4. **每季檢視**：閾值漂移時重算，不手動調到「看起來準」

## 十二、給偉權的操作心法（研究完成前）

1. **大盤紅燈**（`falling_risk` 高 / bear regime）：佈局可選，短線桶當沖/隔日沖少做或不做  
2. **相對高檔**：海選「少追」標籤與大盤高檔重疊 → 寧可錯過不硬追  
3. **相對低檔**：不等最低，等「廣度不再惡化 + 量縮」再分批看個股獲利格  
4. **期貨領跌現貨**：當日盤中勿與聰明錢對作多
