## 已定

| 項 | 決定 |
|---|---|
| 鈕名 | 壓撐觀察 |
| 位置 | 第二排「隔日沖」後；主選單上六下七 |
| 結構 | 同一顆鈕，三種標籤，使用者自選 |

## 三標籤門檻（大數據定案）

| 標籤 | 門檻 | 獨立日 |
|---|---|---:|
| 壓力橫盤 | 同一大量區內，收在〔撐,壓〕恰好 **2** 根日Ｋ | 448 |
| 測壓未破 | 高≥壓、收≤壓且≥撐、收離壓 **≤0.5%**；量縮可加分不強制 | 460 |
| 剛站上撐 | 從破撐回來後，收≥撐連站恰好 **5** 根日Ｋ | 408 |

## 話筒 UX

1. 主鈕「壓撐觀察」→ 三個子鈕（壓力橫盤／測壓未破／剛站上撐）。
2. 按子鈕後，**先出壓力區圖**（`with_nav_signals=True`：導航箭頭／量能訊號／圖例；與點股三張、查股大量區同一套）。
3. 出完圖後附名單卡＋點股列；**點股票一次三張**：①壓力區圖 ②高低溫度卡 ③籌碼。介紹／產業／導航／營收／K線用圖下鈕自選。
4. 偉權哥哥功能全同；Asia/Taipei；官方柱、盤中未收不當收。
