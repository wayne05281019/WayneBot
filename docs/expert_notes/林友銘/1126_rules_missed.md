## 1. 攻擊波 vs 反彈波（結構鐵律）

影格黃框原文要旨：

> 若畫成 5 浪會造成①④重疊且③最短 → 違反攻擊波形態 → **只能畫成奔走 B 的 3 浪**。

口播同向：

- 找不到攻擊形態 → **只能視為反彈波**
- 反彈波就算**創高**仍當反彈波（奔走 B／誘多），後面還會有完整下跌

對我們：大盤教具／結構改判用；**不准**拿去改次級四浪買訊。次級四浪圖也不該只貼綠底數字卻不交代「這是量尺還是攻擊／反彈判定」。

## 2. 失敗 C

- **失敗 C＝不破 A 底**（影格左例 1990～93）
- 與「C＝A×延伸自 B」並列：有的走完整延伸，有的失敗不破 A

## 3. 回升 vs 反彈（格局讀法）

- 市場常講反彈壓 0.382／0.5／0.618；他若判**回升**，反對把這三條當反彈天花板
- 回升格局下，前高 B 下跌的對應關係要重讀，不是同一套「彈完再破底」口號

## 4. 年線＝海平面（攻擊型守線，暫存觀察）

投影片「攻擊型的投資策略」（未過閘、不准進選股勝率）：

1. **本波最低點到或不破年線**（基本門檻）
2. 守線強弱：**季線 > 半年線 > 年線**
3. 營收／毛利／獲利仍正成長（他當季條件）
4. 反彈後前瞻本益比仍在電子平均下緣（估值條件）

口播補句：

- 年線＝市場平均成本／**岸上**；沒到年線先回年線；已不破年線再往季線走
- 假跌破年線（無長黑灌穿）仍可當相對強
- 季線／半年線扣抵轉下＝蓋頭反壓風險（個案八大法則語境）

→ 可靜默對照觀察；**不准**當海選買訊／改黃金買點。

## 5. 綠底倒三角的真意（之前標法不完整）

他圖上的淺綠／點差（如 8834）：

- **不是裝飾**，是 **A 段跌幅量尺**
- 量完之後要拿去自 B 往下投影 C：×1.0／1.382／≈1.444／1.618
- 點差寫在量尺裡可以，但前提是旁邊有延伸目標價；且他的教室圖空白多、K 不擠

我們前一版在次級四浪個股圖只丟「111／1795」進三角、又綠邊又壓 K：

- **意義沒講完**（缺「用來投影哪裡」）
- **視覺不合格**（擋縮圖 K）

修正方向：綠底可留作量尺底色（無邊）；點差改圖例；若要真用林法，下一步才加「自參考樞紐×比率」的虛線目標（仍觀察非買訊）。
