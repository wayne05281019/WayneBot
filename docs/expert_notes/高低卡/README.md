## 准用／不准

- **准**：對卡、決策卡「今日態度」、介紹圖紀律句、分點平均買超（有官方列才畫）。
- **不准**：紅箭頭當黃金買點、紫箭頭過季線／半年線、沿 5／10 日不破就抱、把這 110 篇寫進海選桶、用均價推 120／240／半年／一年主力成本。
