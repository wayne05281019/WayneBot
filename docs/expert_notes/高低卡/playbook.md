## 如何賣（9/4 寫、9/10 再貼）

最高價＝高低格 20高。最高溫＝升降溫主標「最高溫」。

1. **同步**＝同一天兩個都有。這天不標減碼。
2. **不同步**＝只有其中一個（例如最高價但沒有最高溫）→ **直接減碼**。
3. **脫離**＝今天兩個都沒有。先前同步再脫離 → 準備減碼；先前不同步再脫離 → 直接減碼。

「脫離」不是「最高價但沒最高溫」——那句是不同步。9/10 再貼的例子：昨天最高價但沒最高溫 → 直接減碼。

程式：`sell_discipline.py`。不自動賣、不改海選。6547 9/9 官方：收 68.10、獲利 51.2%、20 高、升溫 → 不同步直接減碼。9/10 09:57 盤中 62.90／39.6% 不當收盤；官方收 61.4／36.3%，脫離後仍直接減碼。

## 創區間新高後回測前波高（友達 2409；OHLC 可述）

創 60 日（季）新高後，回測低點對「這波起漲前 5 根的最高」。回測低不低於前波高 4%＝幾乎不破；破了＝這波先當壞了。若同日也是 180 日導航新高，句上標 60／180日。

官方 2409：20260107 高 16.7 創 60／180 日新高；20260203 低 13.30 vs 起漲前 20260105 高 13.85（差約 4%，幾乎不破）；20260731 回測低 22.0 vs 這波起漲前 20.45 不破。顯示在查股協助判斷／介紹圖紀律盒。**不是買訊、不改黃金買點、不進海選、不進飆大。** 不另開 240 日導航。

程式：`hold_prior_wave.py`。

## 如何低買（聯一光 3441、康普 4739）

低點訊號出現 ≠ 買。

1. 大趨勢要向上，題材與獲利跟上，否則免談。
2. 紅箭頭是嘗試標低點，第一根不一定是真低；跌破該低先停損。
3. 也可等站穩月線。波動大通常反彈也大。
4. **獲利還沒離開 0 先不要動作。**
5. 不要跌破前波低，否則底底低。
6. 月營收比前幾月少，主力不會出重手；最好橫盤。
7. 可再等：本益比低、股價低於主力成本（分點真數）、收下影線、獲利離 0。

作者用近半年／一年「合計買超張數＋平均買超成本」判斷低買點在成本上還是下。低於主力成本的低買比較有參考價值。
