# 高低卡作者後段公開紀律（2026/9/4–9/10）

來源：CMoney CaryBot 110 篇裡較後面的 93–110。WayneBot **當紀律讀**。進場仍只認高低卡表，不抄箭頭。

## 如何賣（9/4 寫、9/10 再貼）

最高價＝高低格 20高。最高溫＝升降溫主標「最高溫」。

1. **同步**＝同一天兩個都有。這天不標減碼。
2. **不同步**＝只有其中一個（例如最高價但沒有最高溫）→ **直接減碼**。
3. **脫離**＝今天兩個都沒有。先前同步再脫離 → 準備減碼；先前不同步再脫離 → 直接減碼。

「脫離」不是「最高價但沒最高溫」——那句是不同步。9/10 再貼的例子：昨天最高價但沒最高溫 → 直接減碼。

程式：`sell_discipline.py`。不自動賣、不改海選。

## 如何低買（聯一光 3441、康普 4739）

低點訊號出現 ≠ 買。

1. 大趨勢要向上，題材與獲利跟上，否則免談。
2. 紅箭頭是嘗試標低點，第一根不一定是真低；跌破該低先停損。
3. 也可等站穩月線。波動大通常反彈也大。
4. **獲利還沒離開 0 先不要動作。**
5. 不要跌破前波低，否則底底低。
6. 月營收比前幾月少，主力不會出重手；最好橫盤。
7. 可再等：本益比低、股價低於主力成本（分點真數）、收下影線、獲利離 0。

4739 康普 9/10：區間 77.6～90.2、前低 69.10、量縮、等 9–10 月營收。只當對卡，不當買訊。

## 主力成本（聯發科 2454、國巨 2327）

作者用近半年／一年「合計買超張數＋平均買超成本」判斷低買點在成本上還是下。低於主力成本的低買比較有參考價值。

WayneBot 只畫券商分點表底「平均買超成本」。T86 沒有成本價。沒有官方分點列就不要畫 120／240／半年／一年均價。

## 明確不要畫進程式

- 紫箭頭：帶量突破季線／半年線當起點，沿 5／10 日不破就抱。
- 策略 2：突破 20 日高並站上季線、季線扣抵再過高點。只當說明。
- 均線扣抵等待時間可寫進高低卡說明（交易日／約幾個月），不進海選。
- 紅箭頭當黃金買點。
