## 一、希望學到／產出

- 完全懂波浪、跟得上飆大；高準度判**大盤波浪位階**（八循環＋細微波）。
- 判斷工場：官方柱→標籤→外圍／量價／鐵律殺假→改口條件；**不是漂亮浪線**。
- 產出＝**方向＋幅度**（目標／失效／缺因），不是只猜漲跌。
- 波底↔波頂對得上 **Fib×八浪**；五件／細微波／他說過的能量化成可重用規則（約≥10）。
- **兩套驗證**（教材 vs 語料／變體）比準度，留較準；勝率優先可換測法。
- 旁路實驗室：不影響手機／排程；過閘才上話筒；三鍋分標（他說／我估／實驗室）不准混。
- 後期問：20y 多因子能否回饋話筒案件圖／濾網（仍分軌＋過閘）。
