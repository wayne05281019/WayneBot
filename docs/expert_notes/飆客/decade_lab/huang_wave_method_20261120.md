## 定調（開場）

> 大盤今天再創低 → **不是第二隻腳**，而是 **第五波下跌**。

## 為什麼從「第二腳／三段」改成「五段」

1. 先前估大盤第二腳／三段，是因為一直連動台積電。
2. 這次台積相對強：他仍看台積偏 **三段／第二隻腳**（破底小、軌道偏平≠有效向下推動）。
3. 大盤相對弱：多個明星／電子權值族群大幅拉回，疊勢超過台積 → 大盤走出 **五段式下來**。

## 怎麼拆大盤（之後判斷用）

| 檢查 | 黃的用法 |
|---|---|
| 軌道／斜率 | 有效重點＝破後軌道仍往下；軌道太平＝不像推動五段 |
| 有效重疊 | 只破一點／重疊極小≠有效重疊（台積對照；觀眾問「重疊只有1元」同理） |
| 大盤現況 | 一二三四五往下推動；現在走第五段（細微波可能未完） |
| 第五波中 | 先忍、不要在這裡殺低 |
| 第五波後 | 反彈回某區再評估調節；五段＝一組賣讓結束後才整理／下一主題 |
| 大空頭假設 | 也要五波先走完→反彈→再打；不當下就把第五波當大空頭起點 |

## 細微波是否跌完（個股判定步驟）

黃用畫圖回答留言：個股下跌「有沒有走完」不是看情緒，是看結構是否收斂到 **五之五末端**。

1. **先定調整形**：高檔下來常見 **a-b-c**；標準示範＝**3-3-5**（a 三段、b 三段、c 五段推動下）。
2. **認 c 波五段**：c 內標 ①②③④⑤；⑤ 才是最後一大段下跌。
3. **再拆細微波**：⑤ 這一段本身再拆 **1-2-3-4-5 小段**；**五之五（5 of 5）末端**走完 → 細微波跌完味道才完整。
4. **軌道／有效重點**：同軌往下推動才叫有效；破一點、軌道太平 → 不像有效五段（多拿來對照台積）。
5. **第五波進行中**：先忍住、不必殺低；寧可等細微波走完；差一天＝一根跌停也認（南亞科示範）。
6. **走完後節奏**：反彈回「先前第④波／前一組結構區」再評估要不要調節；被套者不在第五波中殺。
7. **空手選股另條件**：低本益比／錯殺觀察；他口播門檻約「超過約 20 倍先不要考慮」（相對台積估值對照）；不是浪號買訊。
8. **另一種「相對低」**：若前段是上漲五波，回檔到 **次級第④波支撐**（水平對齊前④低）可當相對低觀察（威剛／倚強示範）——仍非話筒買訊。

### 忍住 vs 可觀察（口播節奏）

| 狀態 | 黃怎麼說 |
|---|---|
| 大盤／個股仍在第五段細微波中 | 忍住；不要在這裡殺低 |
| 五之五末端結構已完整（如南亞科當日放大圖） | 相對低／結構漂亮可觀察；仍可能再破一點無關大局 |
| 被套在第五波 | 等反彈回前結構區再評估調節 |
| 空手 | 更謹慎；優先低本益比錯殺，不追高本益比摸底 |
