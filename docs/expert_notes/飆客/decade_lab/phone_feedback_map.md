## 3. 明確不能餵（避免騎亂）

| 禁止 | 理由 |
|---|---|
| path／wave8／急跌勝率 → **海選桶權重／篩選條件** | 海選≠路徑勝率；勝率不准混（§7） |
| decade 練習／飆大概念軌 → **黃金買點／leave_zero 公式** | §4／§12／§13；本題硬規則 |
| 未確認紅箭頭 → 進場 | 只認已過 `ma60_lower` 確認者 |
| `WAVE_NEURONS_MATCH=False` 時 → 個股 5／9／發明浪號 | silent_progress 硬鎖 |
| 持股／觀察／記買入／AI倉假錢 → 選股勝率閘 | 個人本只對照、永不進替換閘 |
| fib soft／seq_f n≪20 → 話筒畫面 | 未過閘；`phone_sync=blocked` |
| 實驗室 textbook 段號 → 飆大回覆冒充他說 | 三鍋不准混標 |
| 均價×張數／三大法人叫主力成本 | §4 假資料禁 |
| OTC／融資缺史 → 腦補柱當官方收 | 缺就標缺 |
| 把 path `amp_pct` 當個股目標價推播 | 大盤幅度≠個股買訊 |

## 4. 優先序與低風險立刻可做

### 優先序（過閘後才動編碼）

1. **大盤／波浪位階**：path 幅度帶＋失效＋`missing` 缺因提示（顯示層；非買訊）。  
2. **共用產業／資金鏈標籤**：洞燭×資金×查股介紹一次統一（與 decade 無關也該做時就做）。  
3. **急跌可沿用旗**：僅大盤環境旁證句；飆大仍只跟他写出清／已點位。  
4. **查股結構／大量區軌道**：wave-fib／fib soft 另開靜默對質軌；贏現況再談顯示。  
5. **海選／剛離零／勝率買點**：decade **不進**；各自多軌回測另件。

### 低風險立刻可做（本 PR **只交地圖**，不改話筒碼）

盤點後：**沒有**不碰買訊、又立刻值得單獨開碼的小改（缺資料提示大盤頁已有一類；path 缺因句若上顯示仍屬「可加測」，應另開小 PR 且預設關閉）。  
下一件建議小 PR（文案級、預設關）：

1. 大盤／波浪位階：`missing`／OTC／融資長史不足時一句「這項因素這次沒官方長史，不納入判斷」（不秀假數）。  
2. 興櫃海選／查股：缺日均價序列提示與 factor_gap「OTC」用語對齊（共用缺資料標籤）。  
3. 查股五張圖說／波浪位階腳註：固定「非買訊・實驗室未過閘不上預測句」（防語音誤解）。
