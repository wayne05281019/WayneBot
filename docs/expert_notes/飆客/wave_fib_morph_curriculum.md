4. **聯想故事**：波浪／黃金切割／型態要叠在同一段**量價＋裸K故事**上，才叫交叉。

6. **不是買訊**；不准寫進海選／黃金買點。

## 1. 波浪（八浪基本形）

- 上升 1–2–3–4–5 走完 → 下降 A–B–C（合稱八浪）。
- 硬規則（他原文靈魂＝兩則鐵律）：
  - ③ 不是最短（實戰常推演）；活畫硬卡：**⑤ 高必須＞ B 高**（否則教錯）。
  - **1–4 不重疊**（他 10/21：穿刺 48066 帶才算不重疊，否則再一組 5 跌）。
- 現況敘事（可改）：五波後下降 ABC · 現在在 C（C3-3）＝**預估**。
- 遠窗先畫「升完⑤」；近窗才特寫 ABC。只畫近窗＝學生不知道 C 從哪來。
- 不准發明個股 5／9；大盤細微波他點過才標。

| 型態語 | 他怎麼用（大盤／外圍） | 活畫怎麼用 |
|--------|------------------------|------------|
| 漲幅愈來愈短＋重疊 | B 波反彈或全波段末端盤頭訊號（10/28） | 遠窗脊線變短可註「末端／盤頭觀察」 |

| 頭肩／頸線 | 費半做頭肩頂、破頸線／回測（先行） | 外圍教具讀費半；加權不發明頭肩 |
| 橫台／中繼站 | 中繼後仍往原方向（南下） | 題旨可寫橫台中繼 |

## 4. 量價關係 · 裸K · 主力意圖（要會聯想故事）

他原文硬句（對質用，不當買訊）：

| 故事骨架 | 他怎麼講 | 活畫怎麼寫 |
|----------|----------|------------|
| 無量下跌≠止穩 | 「今天是無量下跌，後續就是持續下跌（不要搞錯量縮止穩），亂用量價關係」（10/30） | 綠跌＋量縮 → 註「無量續跌風險・非止穩」 |
| 沒爆量＝沒籌碼交換 | 破前低但預估量沒放＝沒止跌訊號（10/22）；散戶還不死心（10/30） | 深跌無爆量 → 「籌碼未換完・止跌未確認」 |
| 主力不是大善人 | 「否則主力將股價拉這麼高，當大善人給散戶賺大錢，最後籌碼都在主力手上怎麼可能」（10/23） | 連跌套牢後勿假設「好心解套」拉回 |
| 套牢鏈 | 一天買入→隔天降套牢→再一天還降＝更多人套 → 主力何必拉上來給大家解套？ | 近窗若「紅漲後連續綠跌」→ 故事句「套牢加深・解套靠主力善意＝低機率」 |
