# 飆客兩年怎麼進步（獨立筆記，不進海選）

語料：CMoney 期股多空雙飆客，2025-08-06～2026-09-10，520 篇。Bot「飆客」區只讀這批，不改高低卡。

## 他怎麼觀察（別人不公開這樣做）

1. **台指期細微波**：夜盤／連續盤 15 分＋60 分數 5 段或 9 段（擴延），不是只看加權日 K。
2. **費半先行**：費半 1-4 重疊＝下跌趨勢化解，台股跟進轉區間（2026-06 講得很清楚）。
3. **台積電量價當龍頭領先**：2025-11-21 公開檢討「11/5 台積電高檔出大量該看、大盤沒出量害他疏忽」。之後常先看台積電止跌／頸線，再換算大盤。
4. **板塊內比整理時間、誰先測高**，不比絕對漲跌。
5. 他明講 KD／MACD／布林不算技術分析；認支撐、窒息量、波浪段數、破線洗盤 vs 出貨。
6. **邊走邊改標籤**：B-a-2 或 a-4 並存，用修正深度事後歸類。

## 為何會進步

- 把錯的公開寫下來（11/21 台積電量價；夜盤擴延沒算到 31800），下一輪觀察清單變長。
- 2025-11 點位被拿去打台指期、賠的人怪他 → 大盤精確點位收斂，改講個股與結構。這逼他把「能講的」變成可重複的結構（5／9 段、1-4 重疊、費半）。
- 主戰場會整族撤換：無人機隔日沖 → PCB／F4 波段 → 記憶體容錯率最高 → 光通訊／散熱。不是一路加碼同一套。

## 問「去年年底做哪檔」

他 2025-12-17 寫記憶體群聯／華邦電到整理末端，美光財報隔日；12/18 美光大漲後說沒買的不要追長紅。之後明講「其他族群不要再介入，專心做記憶體」。同時 PCB 領頭羊台光電、金像電、金居、尖點當做出貨。奇鋐 1/2 出清、勤誠等反彈出清。

所以：**去年年底到開紅盤，他帶著做、且叫人專心做的是記憶體族（南亞科、華邦電、群聯、模組），不是 PCB／F4。**
