## 話筒警語（固定）

`試標・推論／非他原文・非買訊・對質未過閘`

## 實用觀盤交付（必須對使用者有用）

1. **觀測手冊**：夜盤 e-mini → 早盤 TX 確認 → 現貨加權驗證＋SOX 連動；他點過的位／改口條件；鐵律（1–4 不重疊、3 非最短等）可操作化。
2. **波浪位階接入**：按「波浪位階」就能看到手冊摘要＋今日觀測＋警語試標；先文後圖／預渲／快取，解決出圖太慢。
3. **自測套件**：歷史日官方柱考三層鏈；可重跑；錯了除錯再生下一版。
4. **不准**：假資料、改黃金買點、離開敘事進產品、DC 句寫成他說、社團原文上話筒。
