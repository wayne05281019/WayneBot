## 2. 何時改口／何時只觀察

### 改口（必須同時滿足）

1. 較晚層**官方柱**否決較早層假設（例：夜盤偏多但 TX 日盤開盤即弱且失守大量區）；或  
2. 他自己新文改口／取消該位；或  
3. 他點名帶**有效失守**（收盤仍在帶下，非盤中毛刺 alone——毛刺先標「戳測」）。

改口時寫：`prev_hypothesis` → `new_hypothesis`＋觸發層＋官方 OHLC 戳。不准發明他沒說過的新價目標。

### 只觀察（不准改口、不准當確認）

- 觸及未確認（只戳到價、沒收穩／無連 2 收）。  
- 費半與 e-mini 背離尚未被 TX 早盤複核。  
- 休市／北市停班：跳過話筒推播節奏，手冊仍可盤後勾夜盤欄。  
- 缺官方數（`es_f` 只在 payload、夜盤列未齊、加權未收）→ 該格勾「缺」，整鏈不宣判。  
- 近帶邊緣（對齊 Michael 旁軌「近 15K120 不做多／近 60 不做空」精神＝邊緣只觀察；**Michael 軌不混標成他說**）。
