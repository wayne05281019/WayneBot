## 4. 波浪：釘頂→刪去→主波／細微波

### 畫法流程

1. 長時間日 K 釘頂（年高／波段高）  
2. 看不清改小時／15–60 細拆  
3. 多來源並列（黃／飆大／公開型態）分鍋  
4. 鐵律：①④不重疊（楔形例外）、③不能最短  
5. 重疊＝有效 vs 假突破／假破底 → 要量化  

### 巢狀

- 上升：①③⑤＝五波；②④＝三波  
- 下降：A＝五或三；B＝三；**C＝必五**  

### 每天必填 `wave_def_draw`

- `degree_main`／`degree_micro` **分開**（不准混成「大概五波」）  
- `draw_notes_zh`（釘頂、鐵律、等幅／Fib）

## 15. 額度策略（使用者 2026-11-28 改口鎖死）

**正確／完整優先，一次到位。**  
省額度＝省廢話、省重做、省重複載入——**絕對不准**為省錢打折學習深度、少欄、略過量價／同步鏈／主細微波、或草率預估導致還要整包重讀（重讀更貴）。

對齊最高指令：最低耗能、最高效能、**最正確**。正確壓過省；省的不是步驟該做的。

### 15.1 該花就花（不准打折的）

每一開市日 **第一次**就要做到可封存 complete（§9＋§14 全 true），包含：

- 讀夠當日口播／紙圖所需（結構、位階、量價、聯動、教具）——讀不透就不准標 complete  
- 全同步鏈（費半／台指日夜／電子日夜／加權）＋量比價  
- 主波＋細微波定義與試繪  
- 雙分支預估（可對質）＋隔日對質解剖＋交叉學習＋rolling  
- 新教具當日擴充  

**禁止：** 為省 token 只用極短 ASR 摘錄就下判、砍欄位、跳鏈、或「先過再補」。  
**禁止：** 故意做淺導致使用者叫重讀——那叫做錯，不是省錢。

### 15.2 該省就省（不傷結果）

### 15.3 一次到位閘（防重讀）

標 `day_complete=true` 前必須：

1. `no_forget_audit` 全 true  
2. 自評：若只靠本日材料，能否獨立講清主／細微波與隔日雙分支——否＝繼續讀／補欄，不准封存  
3. ASR 品質差 → 加影格／重跑段落，**不准**用糊口播硬判  
4. 封存後原則上不重開；僅 audit 失敗或使用者明示重開  

整包目標：**第一遍 chrono跑完就達精準判斷力**；重讀整包＝流程失敗。
