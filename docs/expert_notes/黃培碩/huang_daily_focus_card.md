# 黃培碩・每一日觀察／推測／記錄重點卡（免提醒）

非買訊。來源：`huang_master_consolidate.md` §0.0b／§0.0c＋`huang_daily_full_suite_gate.md`。  
**不准等使用者提醒。** 漏一格＝當日作廢，從缺日回頭補。

---

## A. 觀察（當日官方＋他說的）

1. **片／開市**：有片或 `absent_open`（休市才 skip）  
2. **波浪**：主波＋細微波；巢狀／中繼／鐵律；紙圖點位只凍他點過的  
3. **量價（飆大：量很重要）**：台指期＋點名股 → 價方向 × 量／20日均（數字）；廣度只輔助  
4. **同步鏈**：TWII＋SOX＋TX日／夜＋TE日／夜（缺＝`missing`）＋廣度  
5. **點名股**：官方 OHLC＋量；族群鏈（有講才填）  
6. **出場／持股環境／夜盤一句／五件＋飆大六桶**（六桶與五件**必含量**）

## B. 推測（寫預估前不准偷看隔日柱）

1. **雙分支**高／低：走勢、浪位、點位、幅度（機率可不同、內容不准同義改寫）  
2. **幅度數字帶**（台指收為參；壓力日加寬上下緣）  
3. **黃金切割＋等幅度**：衝動段 R → 回撤 0.382／0.5／0.618／0.786；延伸 1／1.272／1.618；等幅 1R／0.5R／0.618R  
4. **大盤** `market_power`：浪繪製／確認帶＋幅度  
5. **個股** `stock_quant`：每檔點名股自己的方向期望＋幅度帶（**不准套大盤充當個股**）

## C. 記錄／對質（隔日官方柱）

1. 路徑／浪／位／幅度 hit｜miss｜skew（幅度帶內外要跟判決一致）  
2. Fib／等幅：隔日高低有無觸及  
3. 量價：隔日價×量／均是否 confirm／deny  
4. 個股逐檔 path／amp  
5. 失誤找因＋失敗碼＋成長列＋交叉覆核  
6. 分數板／個股總帳／vnext 更新 → 才准下一日

## D. 破除限制（目標）

**資料夠多 → 量化；量化到一定程度 → 推演**（使用者鎖；永遠記得）。  
波浪繪製確認、點位漲跌幅度、大盤＋個股獲勝率 → 能量化證明變準 → 過閘才升級推演／換話筒。  
不准停在有看有感；不准假資料量化；未過閘推演不准當買訊；不准用 blocked 少做。
