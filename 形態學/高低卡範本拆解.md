# 高低卡範本拆解（依你傳過的截圖 OCR 校準）

> 欄位順序固定：**日期｜股價｜獲利｜高低｜預警｜溫度計｜月乖離｜120日量**  
> 海選「起漲」只看 **獲利** 欄（60 曆日低上來 %），**不要**把月乖離當獲利。

## 範本 A：南亞 1303（8234 對照卡）

| 觀察 | 說明 |
|------|------|
| 獲利計算 | 相對近 60 **日曆日**收盤低，不是 60 根 K 低 |
| 8/28 | 獲利約 129.9%、已遠離低點 → **不是**起漲 |
| 8/24 | 獲利仍高檔；月乖離約 0.3% → 易與獲利混淆，要分欄讀 |
| 實綠底 | 獲利從 **0.0%** 翻到 **>0.0%** 那天才是「剛離零」 |

## 範本 B：某股 2420（你傳的決策卡列）

| 日期 | 獲利（欄位） | 起漲？ | 原因 |
|------|-------------|--------|------|
| 8/6 | 7.5% | ✗ | 早已離低點，非貼零 |
| 8/7 | 7.7% | ✗ | 獲利續升，非剛翻 |
