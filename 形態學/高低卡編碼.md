# 高低卡編碼（海選／LINE 必讀）

程式唯一來源：`decision_card_signals.py`（與 `wayne_navigator` 決策卡同一套）。

## 獲利欄

- **計算**：收盤相對「該日往前 60 個**日曆日**」收盤最低之 %（不是 60 根 K 最低）。
- **顯示**：`f"{值:.1f}%"`（一位小數）。
- **貼零**：顯示 `0.0%`。
- **剛離零（實綠底）**：昨獲利 ≤0.05%、今獲利 >0.05%（`profit_cell_style` / `profit_left_zero_highlight`）。
  - 例：昨 0.0% → 今 0.9% ✓ 實綠
  - 例：昨 0.9% → 今 1.5% ✗ 白底（昨已非貼零）
  - 例：昨 0.0% → 今 5.1% ✓ 卡片仍可能實綠，但**海選起漲不收**（>5% 不像剛起步）

## 預警欄

優先序（與 `get_decision_card` 一致）：

1. 收盤 ≤ 60 日收盤低 ×1.005 → `60低`
2. 月乖離 <0 → `K20低`
3. 收盤 ≥ 20 日收盤高 ×0.99 或 月乖離 ≥4% → `K20高`
4. 否則 `No`

## 起漲桶（leave_zero）

須同時過：

1. **獲利**（任一）  
   - 獲利格實綠（`profit_left_zero_highlight`），或  
   - 雙綠脫離（`double_green_breakout`：昨 0.0% 或 60低/K20低，今非 0.0% 且非 60低）  
   - 且今日獲利 ≤ **5%**（海選上限，與卡片綠底分開）
2. **趨勢**：非下坡；多頭／站上月線，或收在月線上
3. **量**：高低格剛離 20 低，或 120 日量前 20，或 Q60R≥2

## 黃金買點（golden_buy）

- 60 日收盤低（`at_60_low`）+ 獲利 -1.5%～2.5% + 月乖離 <-10%
- 與起漲分桶；下坡末端可進黃金買點，不進起漲
