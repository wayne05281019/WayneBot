## Telegram 會突然沒反應（2026-08-31 確認）

關筆電**不會**弄丟 GitHub 程式，但 **Telegram 機器人要有一台一直開著、一直在跑 `python main.py` 的機器**。

這陣子 Bot 是掛在 Cursor 雲端對話的機器上。對話睡著（你說掰掰、關筆電、長時間沒人回這則對話），輪詢就停了，你在手機打「南亞」不會回。盤後／早上海選用的是「主動寄出一則訊息」，不靠輪詢，所以你會覺得「只有海選那一刻又活了」。

不要把 Cursor 對話當 24 小時主機。要選一個常駐處（只能一個，兩個會搶 Bot）：

- 家裡不關機的電腦或 NAS：`docker compose up -d`（已有 `docker-compose.yml`）
- 或 Render 等雲端常駐 Web（`Procfile` 已是 `python main.py`）

GitHub Actions 只適合 `--once` 盤後，不能整天聽 Telegram。

**已有 Render + UptimeRobot 時：** Telegram 聽筒只能給 Render。Cursor 對話若也 `run_polling`，會把 Render 擠掉；UptimeRobot 綠燈也救不了。已加 `WAYNE_SKIP_POLLING`，Cursor 這側改為只寄海選、不搶輪詢。
